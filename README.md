# Machine Learning & Computer Vision

Applied machine learning from UCSB's ECE 157A: from classic models on tabular data to CNNs and YOLOv5 object detection, with a focus on real industrial and medical datasets. For NLP, generative AI and reinforcement learning, see [ECE157B--ML-AI](https://github.com/tamertamer1/ECE157B--ML-AI).

## Projects

| Folder | Task | Approach |
|---|---|---|
| [`157A HW1`](157A%20HW1) | Predicting abalone age from physical measurements | Data exploration with pandas and seaborn, logistic regression and decision trees |
| [`ECE 157A HW2`](ECE%20157A%20HW2) | Classifying defect patterns on **semiconductor wafer maps** | Hand-engineered image features (OpenCV, scikit-image), decision trees and SVMs |
| [`ECE 157A HW3`](ECE%20157A%20HW3) | Image classification on three datasets: **CalTech-256** objects, **HAM10000** skin lesions, and wafer maps | Neural networks trained in PyTorch |
| [`ECE 157A HW 4`](ECE%20157A%20HW%204) | Detecting **metal surface defects** | Trained a **YOLOv5** object detector on a custom labeled defect dataset |

Each folder includes the notebook and, where available, a written lab report (PDF) with results and discussion.

## Running

Open a notebook in [Google Colab](https://colab.research.google.com/) and run the cells top to bottom. The notebooks download their own datasets.
